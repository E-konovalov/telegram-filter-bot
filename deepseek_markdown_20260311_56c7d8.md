# Telegram Bot Filter для чисел 3000+

Этот бот отслеживает сообщения в Telegram-группах и отправляет уведомления,
когда находит сообщения с числами, начинающимися на 3000.

## 🚀 Функционал
- Мониторинг сообщений в группах
- Поиск чисел по шаблону `3000*` (3000, 30001, 3000999 и т.д.)
- Отправка уведомлений в личные сообщения
- Поддержка вебхуков для хостинга

## 🔧 Переменные окружения
- `BOT_TOKEN` - токен бота от @BotFather
- `YOUR_USER_ID` - ваш Telegram ID
- `WEBHOOK_URL` - URL для вебхука (для Bothost.ru)

## 📦 Установка и запуск
1. Клонировать репозиторий
2. Установить зависимости: `pip install -r requirements.txt`
3. Задать переменные окружения
4. Запустить: `python bot.py`
